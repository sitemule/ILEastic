# Security policy

## Reporting a vulnerability

Please do **not** report security problems in public issues, pull requests or
discussions.

Report them privately through GitHub instead: open the **Security** tab of this
repository and choose **Report a vulnerability**. Only the maintainers can see
the report.

Please include:

- what is affected (file, procedure, version or commit)
- how it can be reached, and what an attacker can do with it
- the steps or a small program to reproduce it, if you have one

We confirm the report, check it, and agree a disclosure date with you. Fixes are
released before the details are made public, normally within 90 days. With your
consent we credit you in the advisory, and we can ask GitHub for a CVE id.

## Supported versions

Fixes go into the current version on the default branch. This project is also
built into IceBreak by System & Method A/S (Sitemule), and IceBreak ships the
fixes in its next release.
